# Rev2：単一基板・裏面ホットスワップ設計

## 採用する構成

- 62 × 80 × 1.6 mmの回路基板1枚、外周R2。
- 8キー＋EC11、キー間隔19.05 mm、RP2040-Zero-Mの配線を維持。
- 上側FR4プレート、FR4スペーサー、分割パネルを廃止。キーを保持するプレートと底面保護は3Dプリント外装で担う。
- キースイッチは表面（F.Cu）から、Kailh CPG151101S11ソケットは裏面（B.Cu）から取り付ける。
- 新基板は `kicad/agentpad_rev2_single.kicad_pcb`。旧 `lower` / `upper` / `panel` ファイルは過去設計で、今回の発注対象ではない。

## 修正した穴と実装方向

旧Rev2の電気ピン位置にあるØ1.5 mmメッキ穴は直付け用で、ソケットの筒状突起を受けられない。今回の設計はその兼用をやめ、Ø3.0 mm非メッキ貫通穴2個と裏面SMDパッド2個に変更した。

すべて**表側から透視した座標**で、スイッチ中心を原点、右を+x、基板下方向を+yとする。

| 要素 | 中心座標 mm | 寸法 |
| --- | --- | --- |
| ソケット突起穴1 | −3.81, −2.54 | Ø3.0 NPTH |
| ソケット突起穴2 | +2.54, −5.08 | Ø3.0 NPTH |
| 裏面パッド1（キー入力） | −7.56, −2.54 | 2.55 × 2.50 |
| 裏面パッド2（GND） | +6.29, −5.08 | 2.55 × 2.50 |
| スイッチ中央ボス | 0, 0 | Ø3.9878 NPTH |
| 5ピンMXの位置決めボス | ±5.08, 0 | Ø1.75 NPTH |

座標と裏面実装は[公開Kailh MXフットプリント](https://github.com/daprice/keyswitches.pretty/blob/master/Kailh_socket_MX.kicad_mod)を照合した。`rev2_back.svg` は実物を裏から見た向きに反転して出力している。

## 3Dプリント外装への引き渡し寸法

`manifest_rev2.json` にキー中心とエンコーダー中心を収録。`cad/rev2_case/plate.scad` は上面プレートの寸法確認用モデル。

- 基板原点は左上。キー中心x=11.95 / 31.00 / 50.05、y=34.00 / 53.05 / 72.10 mm。右下はエンコーダー。
- MXの保持開口は14 mm角を出発点とし、クリップが掛かる部分の板厚は1.5 mm。プリント公差は実物1キーで確認する。
- PCB表面からキー保持プレート上面までは5.0 mmを暫定値とする。購入したMX互換品の図面・実測で確定する。
- MCU部分は20 × 25 mmの上端開放切り欠き。USB、BOOT、RESETへアクセスできるようにする。
- PCB裏面からケース床までは仮に5 mm以上を確保し、ソケット、半田、ヘッダーピン突出量を実測して決定する。
- 四隅にM2用Ø2.2 mm非メッキ穴を配置。左上原点で中心座標は (2.5, 2.5)、(59.5, 2.5)、(2.5, 77.5)、(59.5, 77.5) mm。穴中心の間隔は57 × 75 mm。
- ネジ頭・ケース支柱の基板接触部は外径4 mm以下とする。両面にØ5 mmの銅箔禁止領域を設け、ネジ頭から銅箔まで0.5 mm以上を確保する。皿もみはない。大径ワッシャーは使用しない。
- プリントプレートにも同位置の穴を追加。ケース側の支柱・ネジ長は組立高さに合わせて設計する。キーキャップとネジ頭の上下方向の干渉は実物で確認する。
- ソケットの下に挿入力を受ける支持を設計する。裸の配線・半田点を支持点にしない。

### 3Dプリント外装（実測反映版・ねじ止めなし）

実測値: 基板1.6 mm、基板裏面＋ソケットで3.5 mm（ソケット突出1.9 mm）。

| ファイル | 内容 | 印刷向き |
| --- | --- | --- |
| `cad/rev2_case/plate.stl` | キー保持プレート。四隅に傾き止めの柱（Ø4、基板との隙間0.2 mm） | 上面を下、柱が上。サポートなし |
| `cad/rev2_case/plate_fit_test.stl` | スイッチ開口13.9 / 14.0 / 14.1 mm（切り欠き1 / 2 / 3本） | そのまま |
| `cad/rev2_case/bottom.stl` | 底トレイ。基板裏面から床まで5 mm、壁上端は基板表面と同じ高さ、上辺にUSB側の切り欠き | 床を下。サポートなし |

- 上面はプレートのみの最小構成で、RP2040-Zeroは覆わない。
- 基板は底トレイに載せるだけで、ねじ止めしない。四隅の柱（基板接触部Ø4）と各ソケット下の支え（隙間0.1 mm）で受け、外周の壁（隙間0.3 mm）で位置を決める。支えはスイッチ中央ボスと位置決めピンの突出部を避けている。
- プレートはスイッチのクリップで保持され、スイッチはソケットへの差し込みで基板に固定される。
- 裏返すと基板ごと外れる。ねじ止め版は実物で嵌合を確かめた後に作る。
- ヘッダーピンやエンコーダー端子は、基板裏面から5 mm未満の長さに切る。
- 開口寸法は `plate_fit_test.stl` で確かめ、`plate.scad` の `switch_opening` に反映してからプレートを印刷する。

STLはOpenSCADで再出力する。

```sh
openscad -o cad/rev2_case/plate.stl cad/rev2_case/plate.scad
openscad -o cad/rev2_case/plate_fit_test.stl -D 'part="fit_test"' cad/rev2_case/plate.scad
openscad -o cad/rev2_case/bottom.stl cad/rev2_case/bottom.scad
```

### 熱圧入インサート版の底トレイ

ねじなし版は実物で合うことを確認済み（2026-10-12）。同じ形状で、四隅の柱にM2熱圧入インサート（M2-3-3、長さ3 mm）の下穴を加えた。

| ファイル | 内容 |
| --- | --- |
| `cad/rev2_case/insert_test.stl` | 実物と同じ柱を5本並べた下穴テスト。Ø2.7 / 2.8 / 2.85 / 2.9 / 3.0（台の切り欠き1〜5本） |
| `cad/rev2_case/bottom_insert.stl` | 下穴Ø2.9の底トレイ（insert_testで決定、2026-10-12） |

- 下穴径はinsert_testでØ2.9が最もよかった。
- 下穴は柱の上面から床上1 mmまで（深さ6 mm）。インサート長3 mmに対し、目安の4.1 mm以上を確保している。
- 柱の基板接触部（上端1 mm）はØ4で、Ø2.9の穴だと肉厚が0.55 mmしかない。インサートは柱の上面から1 mm沈め、肉厚1.55 mmのØ6部に埋め込む。
- インサートの上端は基板裏面から1 mm下。上から締めるネジは、基板の下を通ってからインサートに掛かる。
- 下穴の目安は https://ameblo.jp/kabapython/entry-12926756189.html による。

```sh
openscad -o cad/rev2_case/bottom_insert.stl -D 'part="bottom_insert"' cad/rev2_case/bottom.scad
openscad -o cad/rev2_case/insert_test.stl -D 'part="insert_test"' cad/rev2_case/bottom.scad
```

## 組立と確認

1. 裏面の `REV2 SOCKET BOTTOM` を確認し、ソケットの突起をØ3 mm穴に下から入れる。
2. ソケットを基板に密着させ、両端の裏面パッドを半田づけする。キースイッチ自体は半田づけしない。
3. プリントした保持プレートへキースイッチを上から固定し、ピンの曲がりを確認する。
4. 裏面ソケットを支えながらスイッチをまっすぐ挿す。ピンが穴を通ってソケットへ入ることを確認する。
5. 無通電で短絡・導通を確認後、8キーとエンコーダーを動作確認する。

KiCad DRC合格は実物の嵌合を保証しない。Rev1で表側実装になった原因を現物なしで断定はできないため、量産前に1ソケットの裏面嵌合と上下方向を確認する。

## 再生成

```sh
AGENTPAD_OUT=/tmp/agentpad_rev2_single_build .venv/bin/python scripts/generate_agentpad_rev2.py
scripts/run_kicad_drc.sh rev2
```

出力先は使い捨ての空ディレクトリを指定する。製造ZIPにはKiCadが同一座標系で出力した全Gerber、PTH、NPTHを同梱する。
